# HustleHub

HustleHub is a platform where people can post petty jobs and get connected with unemployed people nearby.  
It was originally built as an idea for the **Adapt IT Social Good Hackathon 2025**, and we completed this in just one week.

## Tech Stack
- **Frontend**: EJS, CSS, JavaScript  
- **Backend**: Node.js + Express, Socket.IO  
- **Database**: MongoDB  

## Features
- 🛒 **Marketplace** – Browse and post petty jobs  
- 🗺️ **Maps Integration** – Connect with people nearby  
- 📍 **Location Tracking** – Match workers and jobs in the same area  
- 💬 **Real-Time Chat** – Built with Socket.IO for instant messaging  
- 💬 **Community Forum** – Share experiences and advice  
- 📚 **Learning Hub** – Access resources to upskill  
- 🎓 **Certifications** – Recognised by the HustleHub platform

## About the Project
The goal of HustleHub is to reduce unemployment by creating a space where small, quick jobs can easily connect people who need help with those who need work.  
It’s a **hackathon project**, built in a week, and showcases how tech can be used for social good.
